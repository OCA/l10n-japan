Enter the phonetic reading in **Name (Kana)** on the product template. Variants
inherit it, and a reading typed into a product lookup on an order line finds the
product.

Products follow the kana format configured in **Japanese Kana Name**. To give
them a format of their own, set the
`l10n_jp_name_kana.format.product.template` system parameter — see that module's
usage notes.
