This module stores the postcode of Japanese contacts in one format,
``NNN-NNNN`` by default, whichever way it was entered: without the
hyphen, in full-width digits, with another dash character, or with the
〒 mark and spaces.

The format is applied when a contact is created, when its postcode is
written and when its country or company changes, so it covers imports
and API calls as well as the form. A contact counts as Japanese when its
country is Japan or, with no country set, when its company is in Japan.
For a contact shared between companies, that is the company the user is
working in. A value that does not read as exactly seven digits is stored
as entered, so that it stays visible for correction.

Postcodes already stored are not changed on installation; see *Usage* to
bring them to the format.

Configuration
=============

Go to *Settings > General Settings > Contacts* and choose the *Japanese
Postcode Format*: with hyphen (``810-0041``, the default) or digits only
(``8100041``).

The choice applies to postcodes written from then on. Postcodes already
stored keep their format until they are written again; see *Usage*.

Usage
=====

Postcodes already stored are formatted only when they are written again,
so after installing the module or changing the format setting, older
values may remain in another format. How to rewrite them depends on the
database; one way is to export the contacts' *Zip* with *I want to
update data (import-compatible export)* ticked and import the file back
unchanged.
